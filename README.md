# Credit Risk Default Prediction System

A robust machine learning-based risk assessment platform built to predict borrower default risk for the Lending Club dataset.

## 🚀 Overview
This project processes over 1.3 million loan records to build a professional-grade risk scorecard. It helps financial institutions identify high-risk borrowers using logistic regression and statistical analysis.

## 📊 App Preview
![App Screenshot](assets/app-screenshot.png)

## 🛠 Features
- **Data Pipeline:** End-to-end data cleaning and feature engineering (DTI, Income-to-Loan, Employment Stability).
- **Predictive Modeling:** Statsmodels Logistic Regression for accurate Risk Scoring and Odds Ratios.
- **Interactive Dashboard:** Real-time risk probability calculation using Streamlit.
- **Performance Metrics:** ROC-AUC evaluation to ensure high discrimination power.

## 📈 Key Insights
- Each grade level drop increases default odds by **56%**.
- High DTI (>25%) increases risk likelihood by **11%**.
- Long-term job stability reduces default risk by **9%**.

## 💻 Tech Stack
- **Languages:** Python
- **Libraries:** Pandas, NumPy, Statsmodels, Scikit-learn, Streamlit, Matplotlib
- **Platform:** GitHub, Streamlit Cloud
